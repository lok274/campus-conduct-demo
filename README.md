# 校園訓育系統前端

這個目錄包含 TypeScript、React、Tailwind CSS 製作的訓育介面。

```powershell
npm install
npm run dev
```

目前只有前端示範資料與頁面內暫存狀態。未完成的新增草稿會自動儲存在目前瀏覽器，成功建立後清除；重新整理仍會重置已建立或修改的正式紀錄。

「獎懲紀錄」頁面可將全部紀錄（包括規則、跟進及結案歷史）匯出為 Excel 可開啟的 UTF-8 CSV，再由同一頁匯入。CSV 會顯示學生姓名、班別、座號及學號；巢狀歷史以 JSON 儲存在獨立欄位，確保重新匯入時不遺失。匯入前會驗證格式及學生 ID，並要求確認後才取代目前頁面的紀錄；學生名冊不會隨備份更改。舊版 JSON 備份仍可匯入。

紀錄清單支援跨頁多選，再統一指定負責人、跟進期限或個案狀態。套用前會顯示實際影響筆數及變更摘要；完成後可在下一次紀錄修改前復原最近一次批次變更。批次結案或重新開啟會保留個案歷史。

尚未加入正式登入、角色權限、後端儲存或稽核紀錄，請勿輸入真實學生資料。
