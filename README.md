# 校園訓育系統前端

這個目錄包含 TypeScript、React、Tailwind CSS 製作的訓育介面。

```powershell
npm install
npm run dev
```

目前只有前端示範資料與頁面內暫存狀態。未完成的新增草稿會自動儲存在目前瀏覽器，成功建立後清除；重新整理仍會重置已建立或修改的正式紀錄。

「獎懲紀錄」頁面的 CSV 匯出會採用目前搜尋及篩選後的完整結果（不是只匯出當前分頁）；未設定條件時則匯出全部紀錄。日期篩選無效時會阻止匯出，直至日期修正。CSV 沿用原有欄位格式，可由 Excel 開啟，並包括規則、最後修改時間、跟進及結案歷史；巢狀歷史仍以 JSON 儲存在原有欄位，確保重新匯入時不遺失。匯入前會驗證格式、學生 ID、校本範疇及規則 Code，並要求確認後才更新目前頁面的紀錄；學生名冊不會隨備份更改。JSON 格式備份仍可匯入，但所有紀錄都必須使用現行「守規／勤學／勤到」範疇及校本規則。

紀錄清單支援跨頁多選，再統一指定負責人、跟進期限或個案狀態。套用前會顯示實際影響筆數及變更摘要；完成後可在下一次紀錄修改前復原最近一次批次變更。批次結案或重新開啟會保留個案歷史。

尚未加入正式登入、角色權限、後端儲存或稽核紀錄，請勿輸入真實學生資料。
